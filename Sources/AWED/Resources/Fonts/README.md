# Playtest status fonts

These fonts are bundled for the era-specific status panels. They are all
available under the SIL Open Font License 1.1 from the Google Fonts repository:

- Press Start 2P — https://github.com/google/fonts/tree/main/ofl/pressstart2p
- VT323 — https://github.com/google/fonts/tree/main/ofl/vt323
- Silkscreen — https://github.com/google/fonts/tree/main/ofl/silkscreen
- Share Tech Mono — https://github.com/google/fonts/tree/main/ofl/sharetechmono
- Rajdhani — https://github.com/google/fonts/tree/main/ofl/rajdhani

The license permits bundling and redistribution of the font software. The
source license text is available in each upstream directory.

The editor uses the families as era-matched display faces (not as extracted
game ROM fonts):

- Famicom Wars: Press Start 2P
- Game Boy Wars: VT323
- Super Famicom Wars: VT323
- Game Boy Wars 2/3: Silkscreen
- Advance Wars 1/2: Share Tech Mono
- Dual Strike and Days of Ruin: Rajdhani
